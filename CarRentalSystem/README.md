# Car Rental System
Model a real-world car rental system.

## Scenario
A car rental system rent cars to customers.

A customer can rent car and returns them.

A customer can rent maximum of 2 cars at a time.

## Classes
-Car

 Store the details of car
 
-Customer

  Store the details of car and provide methods to rnet and return car.
  
-Manager

  Store the details of manager and provide methods to add and remove cars in rental system.
  
-RentalSystem

  Acts as a central repository for storing details of customers and cars.
  
-Main

  Handles input and output.

## Workflow

- Create System(car Rental System)

- Create manager 

- Create Customers and add it tp the list

- Manager create cars and add it to the rental system.

- Customer rent cars (status will print) and can return them.
