# AirLines

## Overview
An airline booking system helps to find the cheapest airline based on customer type and date of booking.

## Input Format
`<CustomerType>`

`<Day1>, <Day2>, <Day3>`

### Example
Regular  
Monday, Tuesday, Wednesday  

## Output Format
<cheapest_airline>  

### Example
SkyHigh  

## Project Structure

#### Airline
Stores details of each airline and calculates price  

#### AirlineFinder
Compares the details of each airline and finds the cheapest airline  

#### Main
Handles input and output
